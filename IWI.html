Tri-color rings × palettes

Each ring now carries a different color from its palette. The geometry is traced from your original artwork — same circle sizes, same stroke weight, same overlaps — rebuilt as vectors so each ring can be colored independently. Left ring takes the palette's deep primary, middle the supporting tone, right the accent. Typeface switcher up top works across all six.

Notes. Ring order runs deep primary → supporting tone → accent, left to right, so the mark reads darkest-to-brightest the way the eye scans. Where rings overlap, the later ring passes over the earlier one — if you'd prefer a true woven interlock (each ring alternating over and under, Olympic-style), that's a small change to the vector and I can produce both versions. Because these are now vectors, whichever direction wins exports to SVG at any size with no redraw.
